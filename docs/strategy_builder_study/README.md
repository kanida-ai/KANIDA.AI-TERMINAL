| [03_RUPEEZY_AASTHA.md](03_RUPEEZY_AASTHA.md) | Strategy Store, prediction builder, basket + analyse |

| [raw/](raw/) | Field notes captured while clicking through each app |

**Test-data hygiene:**
- Every test object created during the study was deleted afterwards: the Sensibull saved strategy "KANIDA TEST strgl", the Sensibull draft portfolio "KANIDA TEST PF", and the Rupeezy basket "KANIDATEST".
- No order was placed on any broker.
- No terms or agreements were accepted: the TrendSpider exchange agreement and the Rupeezy expert-recommendation T&C were both left alone.
