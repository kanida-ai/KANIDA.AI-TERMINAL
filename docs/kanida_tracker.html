Net Expectancy — the one metric that decides "sellable"

A worker is sellable if it makes money per trade, on average, after costs — sustained across years. Not precision, not win-rate. The single number:

Net Expectancy = (Pwin × Avg Win) − (Ploss × Avg Loss)  — after costs, per trade

It counts the full return distribution: predict +1%, get +0.7% → booked as a +0.7% win, not a miss. A −3% loss hurts 30× more than a −0.1% loss. We measure it on 2025 and 2026 (clean out-of-sample — patterns were discovered on ≤2024), and "sellable" means expectancy stays positive in both years, ≥ +1%/trade in the worse year. Expectancy is continuous — it ranks, it doesn't flip on a coin-toss — which also fixes the false-negative problem (no worker rejected at an arbitrary cliff).

M12cSeed-stability ensemble — binary "READY" was ~95% luck
What

Mined the same engine under 5 independent random seeds, graded each on the binary 6-test gauntlet, and scored every worker by how many seeds it stayed READY in.

Realized → Workers

Only 2 of ~64 READY workers survive all 5 seeds (ACC, GICRE); each seed's ~60 READY are mostly different stocks. The binary "sellable" set was overwhelmingly seed-noise.

Realized → Goal

Decisive reason to drop binary gates for a continuous metric → motivated the Net-Expectancy reframe (M14).

M12bEvent features as miner inputs — no real gain (variance)
What

Added 6 leak-free event features to the engine and re-mined all 505 symbols in parallel (8 workers, identical per-stock quality) into a separate table. Graded on the same 6-test gauntlet.

Realized → Workers

READY "rose" 54→64, but a same-features different-seed control rose 54→63 — the gain is re-mine variance, and events appear in only 3.8% of patterns. Not adopted. Exposed that READY is seed-fragile → led to the stability ensemble (M12c).

Realized → Goal

Saved us from swapping proven agents (DABUR, INDIGO, M&MFIN) for noise. The honest lever isn't events — it's robustness.

M12Event overlays + stricter bar — tested, don't grow READY
What

Two cheap levers to grow the 54: (a) event/calendar timing regimes, (b) a stricter a-priori ETV bar. Both graded on the full 6-test gauntlet, leak-free.

Realized → Workers

Neither grows READY. Event timing: leak-free gain ≈ +2 (per-worker selection overfits, −8). Stricter bar: survivors' ret/DD rises (2.12→2.52) but the count falls (54→41) as workers lose the trade-sample gate. 54 is the honest ceiling of the current pattern pool.

Realized → Goal

Saved us from shipping an overfit "win". Confirms the real lever is richer signals (M12b re-mine), not post-hoc timing.

M10bA-priori point-in-time selection — the real risk lever
What

Keep a segment for the book only if its ETV on ≤2024 signals cleared a bar; trade kept segments at full breadth (no stops, no reactive weighting). Filter is leak-free vs the eval year.

Realized → Workers

On sealed 2026: zero-parameter rule (ETV>0) lifts ret/DD 0.26 → 0.61, and turns more workers positive (230 → 255). Strict bar (ETV>0.5%) → ret/DD 0.99 on 203 durable workers.

Realized → Goal

Clears gate G5. Profit +76% and drawdown −25% at zero free parameters (up to +134% / −38% tuned) — selection beats reaction. This is the Arena's policy now.

M10Score-conditional leverage + ETV stops — tested, did not pass
What

Full 441-worker sweep isolating each risk overlay (scoring, wick/close stops, leverage) on true portfolio drawdown, 2025–26.

Realized → Workers

Every overlay lowered ret/DD. Scoring alone halved trades (46k→21k) & kept only 41% of profit for 28% less DD; wick-stops kept just 19% with no DD benefit. The raw promoted book (ret/DD 0.73) beat all six variants.

Realized → Goal

Gate G5 not cleared — reactive risk control trades against this edge. Honest correction below. Lever moves to a-priori selection (M10b).
